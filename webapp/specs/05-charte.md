# Charte graphique

## Couleurs

### Palette principale

| Nom | Hex | Usage |
|-----|-----|-------|
| Violet | `#6B5CE7` | Accent principal, boutons, liens, titres |
| Vert | `#2EAD6B` | Carte, éléments graphiques, citations |
| Orange | `#E57C3A` | Point du logo, accents secondaires |
| Crème | `#F5F0E1` | Fond de page |
| Violet foncé | `#3D3270` | Texte principal |

### Couleurs fonctionnelles

| Nom | Hex | Usage |
|-----|-----|-------|

## Éléments graphiques

### Carte du territoire
- Silhouette du Pays Basque en vert `#2EAD6B`
- Style flat, sans relief
- Logo V.E positionné en haut à droite de la carte

### Ligne ondulée
- Bordure gauche des blocs de citation
- Couleur verte
- Style SVG ondulé vertical

### Icônes
- Style ligne (outline)
- Épaisseur 2px
- Couleur violet ou selon contexte
- Suggestion : Lucide Icons ou Heroicons

---

## Espacements

### Grille
- Container max : 1200px
- Padding horizontal : 24px (mobile), 48px (desktop)
- Gap entre éléments : 16px, 24px, 32px selon contexte

### Sections
- Espacement vertical entre sections : 64px
- Espacement vertical entre sous-sections : 32px

---

## Boutons

### Bouton primaire
- Fond : Violet `#6B5CE7`
- Texte : Blanc
- Padding : 12px 24px
- Border-radius : 8px
- Hover : Violet plus foncé

### Bouton secondaire
- Fond : Transparent
- Bordure : Violet 2px
- Texte : Violet
- Padding : 12px 24px
- Border-radius : 8px
- Hover : Fond violet léger

---

## Ombres et bordures

### Ombres
- Cards : `0 2px 8px rgba(0, 0, 0, 0.08)`
- Dropdown : `0 4px 16px rgba(0, 0, 0, 0.12)`

### Bordures
- Cards : `1px solid #E5E7EB`
- Inputs : `2px solid #E5E7EB`
- Inputs focus : `2px solid #6B5CE7`
- Border-radius : 8px (cards), 4px (inputs, badges)

## Responsive

### Breakpoints
- Mobile : < 640px
- Tablet : 640px - 1024px
- Desktop : > 1024px

### Adaptations mobile
- Menu hamburger
- Carte en pleine largeur
- Cards en pile verticale
- Filtres dans un panneau dépliable
